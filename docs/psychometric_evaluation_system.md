# PSJT 心理测量评价体系

## 目的

本体系用于开发期虚拟样本分析，回答两个不同问题：

1. 每道题是保留、修改还是删除；
2. 整套测验目前有哪些信度与效度证据，还缺少哪些证据。

旧版“难度合格、题总相关显著、每个选项选择率至少5%”三项硬性
AND 判定继续保留为论文复现指标，但不再等同于题目质量结论。

## 单题评价

### 1. 区分度

核心证据为：

- 校正题总相关 CITC，避免题目与包含自身的总分相关造成虚高；
- 单题得分与目标构念所对应 Neo-FFI 维度的 Spearman 相关；
- 按目标 Neo-FFI 维度排序后三等分组的低、中、高组题目均分；
- 高组均分减低组均分，方向必须为正。

开发期建议值：

| 等级 | 规则 |
|---|---|
| 强 | CITC ≥ .50，且单题—目标 Neo 维度 ρ ≥ .40 |
| 可接受 | CITC ≥ .30，且单题—目标 Neo 维度 ρ ≥ .30 |
| 边缘 | 任一相关低于上述可接受值，但方向仍为正 |
| 差 | 相关为负或高低组差异方向颠倒 |

14道题的相关检验统一使用 Benjamini-Hochberg FDR 校正。显著性只用于
表达估计不确定性，不替代效应量阈值。

### 2. 得分分布

难度定义为：

`(题目均分 - 理论最低分) / (理论最高分 - 理论最低分)`

| 等级 | 难度 |
|---|---|
| 强 | .30–.75 |
| 可接受 | .20–.80 |
| 弱 | < .20 或 > .80 |

难度弱表示可能存在地板或天花板效应，触发修改，不单独触发删除。

### 3. 选项功能

同时报告：

- 实际被选择过的选项数；
- 选择率至少5%的有效选项数；
- 每个选项选择者在目标 Neo-FFI 维度上的均分。

低于5%的选项是诊断警告，不是自动删题条件。若实际只有两个或更少
选项被使用，则建议修改选项；若仍有三个以上选项工作且区分度良好，
题目可以保留并监测低频选项。

### 4. 信度贡献

比较删除该题前后的 Cronbach α：

- 删除后 α 不升高：支持保留；
- 升高不超过 .01：影响中性；
- 升高超过 .01：需要关注，但只有同时伴随区分度问题时才支持删除。

### 5. 最终建议

| 建议 | 条件 |
|---|---|
| `retain` | 区分度可接受，分布不极端，至少三个选项实际工作 |
| `revise` | 区分度边缘、难度极端或仅两个选项实际工作 |
| `remove` | 区分方向错误、区分度过低，或弱区分度与明显信度损害共同出现 |

## 整卷评价

### 信度

整体同时报告 Cronbach α 和 Spearman-Brown 校正分半信度：

| 等级 | 系数 |
|---|---|
| 强 | ≥ .80 |
| 可接受 | .70–.79 |
| 弱 | .60–.69 |
| 不足 | < .60 |

只有2至3题的 facet 不依据 α 单独宣布为可靠分量表。

### 效度

效度不合并成一个简单分数，分别报告：

目标参照维度由已冻结的 `construct_profile.domain_id` 确定，不由分析程序猜测：

| Big Five domain | Neo-FFI 参照维度 |
|---|---|
| neuroticism | N |
| extraversion | E |
| openness | O |
| agreeableness | A |
| conscientiousness | C |

如果构念档案、需求规格与作答 manifest 的映射不一致，分析应停止并报告配置错误。

- 聚合证据：SJT总分与目标构念所对应 Neo-FFI 维度的相关；
- 区分证据：SJT与非目标人格维度的最大相关，以及目标相关相对它的
  增量；
- 内部结构：EFA/CFA 是否完成；
- 公平性：DIF 是否完成；
- 效标关联或预测效度；
- 真实被试与重测证据。

虚拟SJT和虚拟Neo-FFI由同一人格提示生成，因此相关可能被共同方法和
语义重叠放大。虚拟结果只能标记为开发期证据，不能标记为已验证并用于
正式选拔、诊断或个体高风险决策。

## 程序输出

- `item_quality.csv`：逐题指标、质量等级、建议及原因；
- `measurement_evaluation.json`：整卷信度、效度、证据缺口和使用限制；
- `item_statistics`：保留原论文三项判定，同时增加
  `criterion_discrimination` 和 `quality_evaluation`。
